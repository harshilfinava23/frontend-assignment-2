# Pachyteria - Insect Collection UI

A modern insect showcase landing page built with pure **HTML & CSS**.  
This project focuses on creative split-screen layouts using **Flexbox**, centered positioning, and modern UI styling.

🔗 **Live Demo:** https://pachyteria-ui.vercel.app/

## About

The goal was to build a modern insect collection showcase UI using:
- `display: flex` for split-screen layouts
- Absolute positioning for centered beetle image
- Classification details with clean typography
- Minimal navigation & modern collection panel
- Toggle-style UI components and specimen info cards

No JavaScript. No frameworks. Pure HTML & CSS only.

---

## Tech Used

- HTML5
- CSS3
- Flexbox
- Position Absolute & Relative
- RemixIcon (icon library)
