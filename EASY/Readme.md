# ScaleX Blog UI

A modern dark-themed blog landing page built with pure **HTML & CSS**.  
This project focuses on creating clean layouts using **Flexbox**, responsive sections, and modern UI styling.

🔗 **Live Demo:** https://scalex-blog.vercel.app/

## About

The goal was to recreate a modern blog website UI using:

- `display: flex`
- Clean card layouts
- Hover effects
- Responsive spacing & alignment

No JavaScript. No frameworks. Pure HTML & CSS only.

---

## Tech Used

- HTML5
- CSS3
- Flexbox
